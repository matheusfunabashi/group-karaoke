## Simple code explanations

### app.py

This file starts the server. It loads the settings, creates the app and runs it with Uvicorn. The host address is 0.0.0.0, which allows connections from outside a container. The port is a separate setting and defaults to 8000.

### config.py

This file holds the app settings. Settings groups the port and data folder together. Its properties give the database location and media folder location. The load_settings function reads environment variables and uses default values when they are not set.

### The karaoke app setup file

The __init__.py file in the karaoke package creates the FastAPI app. It creates the database tables if needed, adds the song catalog and prepares a folder for recordings. It also adds the health check and connects the session and recording routes. Finally, it serves saved audio clips and website pages. Clip requests are handled first so the website handler does not catch them by mistake.
